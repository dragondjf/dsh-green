1. 基本用法

rg [选项] 模式 [路径...]              # 在路径中搜索模式
rg [选项] -e 模式 ... [路径...]        # 多个模式
rg [选项] -f 模式文件 ... [路径...]     # 从文件读取模式
rg [选项] --files [路径...]            # 只列出文件，不搜索
命令 | rg [选项] 模式                  # 从管道读取

默认行为：递归搜索当前目录，尊重 .gitignore、自动跳过隐藏文件与二进制文件。

模式以 - 开头时用 -e 或 -- 分隔符，例如 rg -e -foo 或 rg -- -foo。

2. 常用示例

# 搜索
rg "error" src/                          # 在 src 目录找 error
rg -i "todo" .                           # 忽略大小写
rg -l "pattern"                          # 只列出文件名
rg -c "pattern"                          # 统计每个文件的匹配数
rg -n "pattern"                          # 显示行号（默认已有）
rg -C 3 "pattern"                        # 上下文前后各 3 行（-A/-B 单独控制前后）

# 文件过滤
rg --files -g "*.js"                     # 列出所有 .js 文件
rg --files -g "!test/**"                 # 排除 test 目录
rg "pattern" -g "*.md"                   # 只在 .md 文件里搜
rg "pattern" -t js                       # 按类型搜索（rg --type-list 查看类型）

# 忽略规则与隐藏文件
rg "pattern" --no-ignore                 # 忽略 .gitignore
rg "pattern" --hidden                    # 包含隐藏文件/目录
rg "pattern" -uu                         # 完全不过滤（等价 --no-ignore --hidden --binary）

# 其他
rg --json "pattern"                      # JSON 输出（机器可读）
rg --sort modified --files               # 按修改时间排序文件列表
rg --type-list                          # 列出所有文件类型定义

3. 在 DSH 工具内部是如何被调用的

DSH 的 glob / grep 工具不自己搜索，而是以子进程调用本手册的 rg.exe，实际参数为：

rg --no-config --files --glob=<模式> --sort=modified --no-ignore --hidden \
   --glob=!**/.git --glob=!**/.git/** [路径]      # glob 工具
rg --no-config <正则> [路径] ...                 # grep 工具（按工具配置附加 --json 等）
  • --no-config：忽略环境变量 RIPGREP_CONFIG_PATH 与 rg.conf，防止注入任意 --pre 预处理命令（安全考虑）。
  • 退出码语义：0 = 找到结果；1 = 无匹配（正常）；其余 = 错误。
  • 注意：--no-ignore --hidden --sort=modified 会全量遍历目录树再排序，在巨型 node_modules 目录上可能较慢（见 §5 性能提示）。

4. 关键参数速查

参数说明
-e, --regexp <PAT>指定模式（可多次，用于以 - 开头或多种模式）
-f, --file <FILE>从文件读取模式（每行一个）
-i, --ignore-case忽略大小写
-w, --word-regexp整词匹配
-l, --files-with-matches只输出匹配的文件名
-c, --count输出每个文件的匹配次数
-n / -N显示 / 不显示行号
-A/-B/-C <NUM>匹配后 / 前 / 前后 NUM 行上下文
--files只列出文件路径，不搜索内容
-g, --glob <GLOB>文件过滤（可多次；! 前缀表示排除）
-t, --type <TYPE>按文件类型过滤（--type-list 查看）
--no-ignore / --hidden忽略 .gitignore / 包含隐藏文件
-u减少过滤（-uu = 全不过滤）
--jsonJSON 行输出（匹配/上下文/摘要）

-m, --max-columns单行最大输出宽度
--no-config忽略配置文件与环境变量
-h / --help简短 / 完整帮助

5. 性能与 Win7 注意事项

  • 大目录树全量扫描：--no-ignore --hidden --sort=modified 会遍历所有文件再排序。实测本机（Win7 + 机械盘）对整个工作区（含数万 node_modules 文件）的 *.md 列表约需 26 秒，接近 DSH 工具 30 秒超时上限。建议搜索时限定路径或更精确的 glob。
  • 不要使用 rg 14.x：若 rg.exe 被还原为 14.x（如 npm 重装依赖后），rg --version 会直接崩溃（退出码 -1073741819）。用 §6 方法重新替换。
  • 替换后无需重启：DSH 每次调用都新起 rg 进程，替换二进制即时生效。

6. 替换 / 还原二进制

# 替换为 13.0.0（从本包 bin 的 zip 解压）
cd /d "%~dp0.."  # 到 dsh-green 根目录
mkdir rg13tmp && tar -xf bin\rg-13.0.0.zip -C rg13tmp
copy /y rg13tmp\rg.exe node_modules\@deepseek-ai\dsh\node_modules\@vscode\ripgrep-win32-x64\bin\rg.exe
rd /s /q rg13tmp

# 还原为原 14.x（备份）
copy /y node_modules\@deepseek-ai\dsh\node_modules\@vscode\ripgrep-win32-x64\bin\rg.exe.bak-rg14 ^
      node_modules\@deepseek-ai\dsh\node_modules\@vscode\ripgrep-win32-x64\bin\rg.exe
zip 内实际路径为 ripgrep-13.0.0-x86_64-pc-windows-msvc\rg.exe（Win7 无 tar 时可参考绿色包手册中的 PowerShell 解压方式或用 7-Zip 等工具）。
