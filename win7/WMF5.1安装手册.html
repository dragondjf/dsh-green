1. 为什么需要它

DeepSeek Harness（DSH）的 pwsh 工具通过 powershell.exe 执行命令。Windows 7 SP1 自带的 PowerShell 只有 2.0，存在两个实际问题：

  • 中文输出乱码：DSH 会注入 [Console]::OutputEncoding = [System.Text.UTF8Encoding]::new($false) 强制 UTF-8，而 ::new() 语法是 PS 5.0 才引入的，2.0 不支持，导致编码设定失败、中文变乱码。
  • stderr 噪音：上述 preamble 在每条命令执行前都报两行 MethodNotFound 错误。

安装 WMF 5.1（Win7 官方支持的最高 PowerShell 版本）即可同时解决这两点，并带来 Get-CimInstance 等现代 cmdlet。无需安装 pwsh 7（7.1+ 基于 .NET 5+，不支持 Windows 7；7.0 已停止维护）。

2. 适用系统与前置条件

系统Windows 7 SP1（x64）／ Windows Server 2008 R2 SP1（x64）
.NET Framework需要 4.5 或更高（本机已装 4.7.2，满足）。检查：(Get-ItemProperty 'HKLM:\SOFTWARE\Microsoft\NET Framework Setup\NDP\v4\Full').Release 应 ≥ 378389
权限需要管理员权限（标准用户安装时会弹出 UAC 凭据框，需要管理员账户的用户名和密码）
磁盘需要约 1 GB 可用空间（安装过程有临时展开）

3. 安装步骤

方式 A：图形界面（推荐）

  1. 打开目录 C:\Users\yfjz\Downloads\dsh-web-0.1.0-rc.5-win32-x64\bin\
  2. 双击 Win7AndW2K8R2-KB3191566-x64.msu
  3. 弹出 UAC 提示：标准用户输入管理员账户凭据，管理员账户点"是"
  4. 等待"Windows Update 独立安装程序"执行完毕（约 5–15 分钟，有进度条）
  5. 按提示重启计算机完成文件替换与引擎注册

方式 B：命令行（静默安装）

以管理员身份打开命令提示符（开始菜单搜索 cmd → 右键 → 以管理员身份运行），执行：

wusa.exe "C:\Users\yfjz\Downloads\dsh-web-0.1.0-rc.5-win32-x64\bin\Win7AndW2K8R2-KB3191566-x64.msu" /quiet /norestart

返回码含义：0 成功；3010 成功但需重启；2359302 (0x240006) 需重启；5 权限不足；0x80070643 安装失败。

4. 标准用户（无管理员）说明

本机账户 yfjz 为标准用户（不在 Administrators 组），且内置 Administrator 账户默认被禁用。安装时必须在 UAC 凭据框中输入任一管理员账户的用户名和密码；若没有任何管理员凭据，则无法安装系统级组件，需先在安全模式下启用/重置管理员账户，或使用具备管理员权限的账户登录。

从 DSH 内部无法可靠弹出 UAC 凭据框（Start-Process -Verb RunAs 会返回"拒绝访问"），因此在资源管理器中手动双击 MSU 是最可靠的安装方式。

5. 重启

WMF 5.1 的文件替换、powershell.exe 版本切换与 PS 3.0 引擎注册在重启后才完成。重启前 QFE 补丁列表已可见 KB3191566，但 PowerShell 仍是 2.0，属正常现象。

6. 安装后验证

重启后打开 PowerShell 执行以下命令，全部符合即安装成功：

$PSVersionTable.PSVersion                 # 应显示 5.1.xxxxx
[System.Environment]::Version               # 应显示 4.0.30319.xxxxx
(Get-ItemProperty 'HKLM:\SOFTWARE\Microsoft\PowerShell\3\PowerShellEngine').PowerShellVersion   # 5.1.xxxxx
Get-CimInstance Win32_OperatingSystem | Select-Object Caption   # 现代 cmdlet 可用
Write-Output '中文测试：你好，世界'          # 中文无乱码

对应 DSH 的 pwsh 工具：每条命令不再出现 [System.Text.UTF8Encoding] 的 stderr 报错，中文输出正常。

0x80240017 / 0x800f0826"不适用"：可能已安装过 WMF 5.1，或系统/架构与包不匹配（本包仅 Win7/W2K8R2 x64）。
重启后仍是 2.0重启未生效或安装未真正完成；确认 QFE 列表存在 KB3191566，再重启一次。
标准用户无法提权需要管理员账户凭据；见第 4 节。
DSH pwsh 中文乱码 / ::new() 报错说明实际引擎仍是 2.0，检查是否已重启。
DSH 沙箱模式下 pwsh 启动失败（乱码的"Windows PowerShell 初始化失败"）沙箱受限令牌会阻止 PowerShell 读取注册表；将该会话切换到 danger-full-access 模式（/permission 或 设置 → General → 权限预设）。

8. 与 DSH 的集成说明

  • DSH 的 pwsh 工具每次调用都会新起 powershell.exe 进程，安装 WMF 5.1 并重启后自动使用 5.1，无需修改任何 DSH 配置。
  • 本安装程序作为绿色包依赖存放在 bin\ 目录，可随绿色包整体拷贝到其他 Win7 x64 机器离线安装。
  • 文件完整性：可执行 Get-AuthenticodeSignature "…\bin\Win7AndW2K8R2-KB3191566-x64.msu"，Status 应为 Valid，签名者 CN=Microsoft Corporation。
